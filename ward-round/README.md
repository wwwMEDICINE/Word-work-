# Ward Round Board

เทมเพลตราวน์วอร์ดสำหรับทีมแพทย์/พยาบาล (`index.html`)

- ตารางตามเลขเตียง: ชื่อย่อ อายุ/เพศ วันที่ admit (D1, D2…) และ Diagnosis
- Active problems แบบ problem list (#1, #2…)
- Ward work เป็น checklist ติ๊กได้ทันทีระหว่างราวน์ และเพิ่มงานใหม่ได้ในแถว
- สถานะ Discharge: Unstable / ยังไม่พร้อม / วางแผน D/C / พร้อม D/C / D/C แล้ว พร้อมวันที่คาด D/C และสิ่งที่รอ
- Consult panel: รวม consult ทุกเตียงแยกตามแผนก พร้อมสถานะ (ยังไม่ได้ส่ง / ส่งแล้ว / ดูแล้ว / sign off) และป้าย STAT
- ปุ่ม “สรุปส่งเวร / LINE” สร้างข้อความสรุปไว้คัดลอกไปวาง
- ปุ่ม “เริ่มราวน์วันใหม่” ล้างงานที่ทำเสร็จแล้ว และเอาผู้ป่วยที่ D/C แล้วออก

## การแชร์ให้ทีม
เมื่อเปิดเป็น Claude artifact ข้อมูลจะเก็บในฐานข้อมูลที่แชร์กันแบบ real time ทุกคนที่ได้รับสิทธิ์ (Contributor ขึ้นไป) แก้ไขได้ ผู้ที่ได้สิทธิ์ Viewer อ่านได้อย่างเดียว
ถ้าเปิดไฟล์นี้ตรงๆ ในเบราว์เซอร์ ข้อมูลจะเก็บในเครื่องนั้นเท่านั้น

**ความเป็นส่วนตัว:** ใช้เลขเตียงและชื่อย่อ อย่าใส่ชื่อเต็ม HN หรือเลขบัตรประชาชน
